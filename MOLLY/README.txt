МОЛЛИ — AI-помощник ПТО
=======================

Локальный помощник для работы с проектной и исполнительной документацией.
Работает на вашем компьютере: документы остаются у вас и никуда не отправляются.
Языковая модель — через Ollama (тоже локально).


БЫСТРЫЙ СТАРТ
-------------
1. Распакуйте архив в удобную папку, куда у вас есть право записи
   (например, D:\MOLLY). Не в Program Files.
2. Установите Ollama: https://ollama.com/download  и запустите её.
   Загрузите или создайте модель (например, свою molly-pto).
3. Дважды щёлкните  start.bat.
   При первом запуске (нужен интернет, один раз) он сам найдёт или
   установит Python и поставит нужные компоненты. Дальше интернет не нужен.
4. Откроется браузер с МОЛЛИ. Мастер первой настройки проведёт по шагам:
   Ollama -> модель -> рабочая папка -> индексация -> имя и стиль -> почта.
5. Закрыть МОЛЛИ: закройте чёрное окно start.bat.

Если браузер не открылся сам: http://127.0.0.1:8000


ЧТО УМЕЕТ
---------
* Чат в стиле современных ИИ-ассистентов: история чатов, остановка генерации,
  светлая и тёмная тема.
* Рабочая папка проекта (например, D:\1. МДП Каркатеевы\1. МДП Каркатеевы):
  PDF, DOC, DOCX, XLS, XLSX, XLSM, TXT, CSV, XML, JSON. Файлы только читаются.
  DWG показываются в списке, но чертёж не читается.
* Индекс документов обновляется сам: новые, изменённые и удалённые файлы
  подхватываются (интервал — Настройки -> Документы). Работает и после
  перезапуска: изменения, сделанные пока МОЛЛИ была выключена, учитываются.
* В ответах по документам показываются источники: файл, путь, страница или
  лист и фрагмент. Номера [1], [2] в тексте ведут к источникам.
* Исключения из индекса: папки, файлы и маски (*.bak).
* Почта (Яндекс): чтение, поиск, вложения, ответ, создание письма. Письмо уходит
  только после подтверждения в окне предпросмотра. Кнопка «Спросить МОЛЛИ»
  передаёт текст письма в чат.
* Сервер в локальной сети: Настройки -> Сервер. Другие компьютеры открывают
  МОЛЛИ в браузере по адресу вида http://192.168.1.100:8787 и входят по токену.
* Настройки: имя, стиль, длина ответов, системный prompt (можно загрузить из
  файла), модель и её параметры, тема, исключения. Экспорт и импорт настроек,
  автоматические резервные копии, диагностика и журнал.


ЯНДЕКС.ПОЧТА — КАК ПОДКЛЮЧИТЬ
-----------------------------
Используется IMAP/SMTP — штатный способ Яндекс.Почты.
1. Яндекс.Почта -> Настройки -> Почтовые программы: включите доступ по IMAP.
2. id.yandex.ru -> Безопасность -> Пароли приложений: создайте пароль
   для почты.
3. В МОЛЛИ: Настройки -> Почта: адрес и этот пароль приложения.
Пароль хранится в защищённом хранилище Windows (DPAPI): расшифровать его может
только ваша учётная запись Windows на этом компьютере. В файлы настроек,
экспорт и журналы пароль не попадает.


СЕРВЕР В ЛОКАЛЬНОЙ СЕТИ
-----------------------
Включение: Настройки -> Сервер -> «Запустить сервер в локальной сети».
* Пока сервер выключен, порт закрыт.
* Принимаются только адреса локальных сетей (192.168.x.x, 10.x.x.x,
  172.16-31.x.x). Из интернета доступа нет, даже при пробросе порта.
* Вход — по токену. После 5 неверных попыток IP блокируется на 5 минут.
  «Создать новый» токен отключает всех подключённых.
* Другим компьютерам доступны чат и поиск по документам; у каждого своя
  история чатов. Настройки, почта, выбор папки и управление сервером — только
  на основном компьютере.
* При первом включении Windows может спросить про брандмауэр —
  разрешите доступ для частных сетей.
* Связь идёт по http без шифрования — используйте в доверенной сети.
* Когда сервер включён и вы создаёте нагрузку (много пользователей), ответы
  идут по очереди: модель одна.


ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------
Всё в папке data\ рядом с программой:
  settings.json     настройки (резервные копии — data\backups\)
  chats.sqlite3     история чатов
  projects\         индекс документов (по одной базе на рабочую папку)
  secrets.json      зашифрованные пароли (только эта учётная запись Windows)
  logs\molly.log    журнал работы
Для переноса на другой компьютер скопируйте всю папку; пароль почты придётся
ввести заново (он привязан к учётной записи Windows).
Обновление: замените папки backend и frontend, папку data оставьте.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
Настройки -> Данные -> «Запустить диагностику»: проверит Python, компоненты,
Ollama, модель, папку, индекс, доступ на запись. Журнал: «Показать журнал».
* «Ollama недоступна» — запустите Ollama; адрес по умолчанию
  http://127.0.0.1:11434 (Настройки -> Модель).
* «Модель не найдена» — выберите модель из списка или: ollama pull <имя>.
* «Порт уже занят» — МОЛЛИ уже запущена (откройте http://127.0.0.1:8000) или
  задайте другой порт: переменная окружения MOLLY_PORT.
* Не хватает памяти — в Настройки -> Модель уменьшите «Контекст» или выберите
  модель поменьше; «Держать модель в памяти» = «Сразу после ответа» освобождает
  оперативную память, когда вы не пользуетесь МОЛЛИ.
* Сбой установки при запуске — проверьте интернет, удалите папку .venv
  и запустите start.bat снова.


ОГРАНИЧЕНИЯ (честно)
--------------------
* Отсканированные PDF (картинки без текстового слоя) не читаются: распознавания
  текста (OCR) нет. Такие файлы попадут в индекс по имени и метаданным.
* DWG — только в списке документов, содержимое чертежа не читается.
* Старый формат DOC читается встроенным разбором без Word; на нестандартных
  файлах возможна неполная выдержка текста. Рекомендуется DOCX.
* Формулы Excel индексируются как значения, сохранённые в файле. Если файл не
  открывали в Excel после изменения формул, значения могут быть пустыми.
* Яндекс.Почта: подключение по паролю приложения (OAuth не используется).
  Безопасное хранилище паролей работает только в Windows.
* Качество ответов зависит от выбранной модели. МОЛЛИ показывает источники —
  проверяйте важные данные по исходным документам.
* Автоматическая установка Python через winget работает на Windows 10/11
  с установленным App Installer; иначе поставьте Python вручную.


КАК ПРОВЕРЯЛОСЬ
---------------
Автоматически проверены: индексация и повторная индексация (изменённые,
удалённые, исключённые файлы), поиск, подбор фрагментов со страницами и
листами, потоковый чат с остановкой и повтором, ошибки Ollama (не запущена,
нет модели), настройки (проверка значений, импорт/экспорт, резервные копии,
восстановление повреждённого файла), история чатов и разделение пользователей,
доступ из сети (токен, ограничение попыток, запрет внешних адресов, защита
от запросов с чужих сайтов), почта на тестовых IMAP/SMTP-серверах,
интерфейс (все разделы, мастер, чат, почта) на тестовом окружении.
Не проверялись в реальных условиях: работа на Windows 11 и в браузере
(вид и масштабирование 100–150%), реальные Ollama, Яндекс.Почта, PDF и DOC
из вашего проекта, подключение второго компьютера по Wi-Fi/LAN, хранилище
паролей DPAPI. Если на каком-то шаге что-то идёт не так — диагностика и журнал
покажут причину.
